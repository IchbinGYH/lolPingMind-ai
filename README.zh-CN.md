# lolPingMind-ai

用信号标记屏幕内容，让 AI 帮你解释、提取、翻译和排查问题。

[English](README.md) | 简体中文

lolPingMind-ai 基于 Danrui Meng 的开源桌面信号轮盘项目 [lolPing](https://github.com/darrenprx/lolPing) 二次开发，是独立的衍生项目，不是 lolPing 官方版本。它保留原项目的轮盘、动画、音效、表情和房间功能，增加截图动作、问答窗口、本机待办和手动框选截图。

软件不会读取或修改英雄联盟本体。AI 动作处理的是桌面上可见的内容，例如文档、图示、代码、表格和报错。

## 能做什么

| 信号 | 单次标记的动作 |
| --- | --- |
| 敌人消失，黄色问号 | 解释截图内容 |
| 危险／撤退 | 检查可见操作的风险和影响 |
| 推进 | 给出接下来可执行的 1～3 个步骤 |
| 正在赶来 | 保存本机待办和截图，可选生成简短标题 |
| 全力进攻 | 使用更高思考档，深入分析图示、公式或代码 |
| 请求协助 | 排查问题并给出修复建议 |
| 需要视野 | 提取文字、Markdown、CSV 或 LaTeX |
| 敌方视野 | 通过 Wikipedia 和 Crossref 查找背景和候选出处 |
| 诱饵 | 检查假设、薄弱环节和反例 |
| 反向问号 | 翻译为中文或英语，并解释专业术语 |
| 视野已清除 | 清除本机标记、收起助手并取消当前及排队动作 |
| 普通信号 | 仅显示普通信号，不发起 AI 请求 |

请求使用你选择的回答服务。“全力进攻”启用更深的思考，可能需要更久。助手给出内容和建议，不会替你执行命令或操作其他程序。

## 运行项目

本分支在发布独立安装包前以源码形式提供。原项目的安装包不包含这里的 AI 功能。请运行这份源码，或在后续发布后使用明确标注为 lolPingMind-ai 的安装包。

### 环境要求

| 平台 | 要求与状态 |
| --- | --- |
| Windows | Windows 11 x64；从源码构建需要安装 Visual Studio 2022 的“使用 C++ 的桌面开发”工作负载。AI 流程已在 Windows 上实机检查。 |
| macOS | macOS 13 或更新版本、Apple 芯片；构建需要 Xcode 命令行工具。继承的移植为实验状态，本分支的 AI 流程尚未在真实 Mac 上检查。 |
| Linux | x64、真正的 X11 会话、合成器、C++20 编译器、XInput 2.1 和 XTest。实验状态，不支持 Wayland 或 Wayland 下的 XWayland。详见 [Linux 说明](docs/linux.md)。 |

所有源码构建都需要 Node.js 22.12 或更新版本及 npm。在下载的项目文件夹中打开终端：

```sh
npm ci
npm run build:helper
npm run dev
```

如果依赖已安装，但 Electron 程序没有下载，运行已安装包自带的下载脚本后重试：

```sh
node node_modules/electron/install.js
npm run dev
```

macOS 可用 `xcode-select --install` 安装编译工具。请为应用或运行输入助手的终端允许“辅助功能”，并在系统提示时允许“屏幕录制”。Debian/Ubuntu 构建前需要安装 `build-essential libx11-dev libxi-dev libxtst-dev`。Linux 桌面还需要可用的托盘，GNOME 可能需要 AppIndicator 扩展。

### 配置你自己的回答服务

打开“设置 → 屏幕助手”，选择一种服务：

| 服务 | 配置方法 |
| --- | --- |
| DeepSeek | 选择 DeepSeek，填写你自己的 API Key，保存后测试连接。当前实现向 `api.deepseek.com` 发送图片请求，模型为 `deepseek-flash`。你的账户需要具备该模型及图片请求的访问权限。 |
| Codex | 打开并登录 Codex 桌面应用，同时确保它的命令行工具可用。选择 Codex，等待就绪状态。当前集成使用已有登录，复用一个专用 Codex CLI 会话，不会模拟往桌面应用的聊天框里打字。 |

项目不附带 API Key、Codex 账户或付费服务权限。每位用户都需要配置自己的账户，请求使用该账户的余额或服务额度。DeepSeek Key 可在设置中保存、更换、测试或删除，保存后的值不会回显到界面。

DeepSeek 连接测试只检查模型列表接口，不发送图片。Codex 模式当前使用 GPT-6 Luna：普通请求采用低思考档，“全力进攻”采用更高思考档。就绪状态表示本机前置条件已满足，不代表之后的网络请求一定成功。

如果只想发普通信号，请选择“仅使用普通信号”。回答服务不可用时，“正在赶来”仍可保存本机待办。

## 快速上手

1. 选择已经配置好的回答服务，并启用“全部屏幕动作”或“仅问号解释”。
2. 将你想了解的内容放到前台。
3. 按住 Alt，用鼠标左键拖动打开轮盘，松开在所需符号上。“敌人消失”是黄色问号，默认布局中向左滑动即可选中。
4. 单次标记会等待 1.2 秒以合并连续标记，再围绕轮盘起点截取固定范围，约为 960×620 个显示无关像素。
5. 截图完成后，问答窗口会自动来到前台，在请求进行时保持置顶。你可以阅读、复制结果，或用同一张截图执行另一个动作。

中文问号解释的问题保持为 `这个截图里的内容是什么意思`。其他符号使用各自对应的动作提示。

### 自己选择截图范围

在同一块屏幕上，1.2 秒内连续打两次相同符号，会用手动框选替代这一组标记原本排队的固定范围截图：

1. 软件冻结这块屏幕的干净画面，打开框选界面。
2. 按住鼠标向任意方向拖出矩形。
3. 拖动选框内部可移动，拖动八个控制点可调整大小；点击“重新框选”可清空选框。
4. 点击“确认截图”或按 Enter 提交。Esc 或右键取消，不发送这一组标记的图片，也不会补发固定范围截图。

画面在框选界面出现前截取。发送给 AI 的图片不会包含信号图标、选框、控制点或按钮。请在打信号前让目标内容保持可见。

启用全部屏幕动作时，每个符号都支持框选。普通信号和“视野已清除”连打两次时使用截图解释；第一次“视野已清除”仍会立即清理工作区。“仅问号解释”模式只响应问号，“仅使用普通信号”模式不打开框选。框选期间继续打符号不会再打开多个选框。

### 快捷键和轮盘

| 操作 | 默认方式 |
| --- | --- |
| 打开信号轮盘 | Alt + 鼠标左键拖动 |
| 打开表情轮盘 | Ctrl + 鼠标左键拖动 |
| 取消轮盘 | 在中心松开、右键或 Esc |
| 暂停／恢复 | Ctrl + Alt + P |
| 打开设置 | 点击托盘图标 |
| 退出或重启输入助手 | 托盘右键菜单 |
| 确认框选 | Enter 或“确认截图” |
| 取消框选 | Esc、右键或“取消” |

macOS 的信号键是 Option，表情键是 Control，暂停键是 Control + Option + P，设置入口在菜单栏。触发键和暂停快捷键均可修改。Alt + 单击放置信号默认关闭。

默认轮盘从正上方开始顺时针为：危险、推进、正在赶来、全力进攻、请求协助、需要视野、敌人消失、敌方视野。在“设置 → 轮盘”中，可将额外符号拖到扇区或中心。表情也有独立的八槽轮盘。

## 问答窗口、队列与待办

- “记录”在本次运行的内存中保留最近 24 条，显示动作、截图、问题和回答。可以筛选、切换记录，或通过“管理”删除单条和清空记录。
- 截图下方可切换动作，无需再次截图。提取支持文字、Markdown、CSV、LaTeX；翻译支持自动、中文和英语。结果可以复制。
- 最多同时进行一个 AI 动作，排队一个后续动作。短时间内不同符号合并为最后的动作和位置，连续两个相同符号则进入框选。已经确认的后续截图会等待当前回答，不会另开多个会话或并行请求。
- 来源检索显示 Wikipedia 摘要、Crossref 论文元数据及链接。这些是候选出处，不代表观点已得到证实，也不代表已经读过论文全文。
- “正在赶来”先保存本机待办和截图。所选服务可用时，可能发送截图生成简短标题，最多等待八秒。服务不可用也能保存；你可以改名、完成和删除。手动编辑的标题优先于迟到的模型建议。
- 最多保存 100 条待办，重启后保留。删除待办也会删除对应本机图片；清空记录或工作区不会删除已保存的待办。从设置打开助手可以直接查看，无需再次截图。
- “视野已清除”会取消当前及排队动作，并移除本机标记。关闭问答窗口与删除记录、删除待办是不同操作。

## 其他设置和房间

信号大小、时长、音量、静音、轮盘大小、保留最新信号、开机启动和中英文切换均保留。支持自定义表情图片和本机音效。Windows 的“全屏程序中暂停”让全屏应用保留输入；窗口化游戏可能需要手动暂停。

房间保留原项目的局域网和公共中继功能。在“设置 → 房间”中创建房间，复制房间码发给朋友；朋友粘贴加入，或使用托盘中的“从剪贴板加入”。最多八人共享信号和表情。信号按对应编号的显示器映射，没有对应显示器时使用主显示器。

房间的初始显示名来自本机操作系统用户名；如果希望使用其他昵称，请在加入前修改。“房间静音”、成员接收上限和“允许互联网连接”控制接收与联网。自定义表情可共享静态小图，动画和自定义声音留在本机。“显示好友的自定义表情”控制两个方向的静态图片传输。

房间成员的信号不会触发 AI。截图、AI 问题、回答、API Key 和本机待办都不会通过房间发送。

房间消息使用由房间码生成的密钥加密，成员可以看到共享的昵称和内容。局域网成员可以看到本地 IP；公共中继可以看到 IP、匿名房间标识和消息时间。关闭“允许互联网连接”即可只走局域网。

## 隐私与本机数据

### 联网目标

| 目标 | 何时连接、发送什么 |
| --- | --- |
| `api.deepseek.com/chat/completions` | DeepSeek 模式发送确认后的或自动裁剪的截图、动作提示，以及用于认证的个人 Key。“正在赶来”也可能请求生成待办标题。 |
| `api.deepseek.com/models` | 点击测试连接时发送认证信息，不发送截图。 |
| 通过已安装 CLI 连接的 Codex 服务 | Codex 模式使用已有登录发送截图和问题。 |
| `en.wikipedia.org/w/api.php`、`zh.wikipedia.org/w/api.php`、`api.crossref.org/works` | 仅在来源检索时发送模型生成的检索词，不发送 API Key 或图片。查到的资料随后与截图一起交给所选回答服务。 |
| 局域网／配置的公共 Nostr 中继 | 加入房间后传输加密的信号、表情静态图和成员资料消息。参见[中继列表](src/main/relays.ts)。 |
| 来源网站／上游 GitHub 主页 | 仅在你主动点击来源或“原项目主页”时由浏览器访问。 |

在本分支配置独立发布渠道之前，继承的 GitHub 自动更新器已关闭，不会下载安装原版 lolPing。源码构建和打包命令不会自动发布版本。

DeepSeek Key 使用 Electron safeStorage 加密，单独保存，不写入普通设置。加密不可用时不会退回明文保存；Linux 需要可用的凭据后端。图片和回答由所选服务按该账户的设置及政策处理。清空本机记录不会删除服务端记录或 Codex 会话历史。

框选时的整屏快照保留在内存中，只有选中范围会发送或保存为待办。普通截图记录保存在内存中；Codex 集成会写入临时裁剪 JPEG 和回答文件，并在请求后移除。

### 数据目录

为兼容已经保存的设置、Key、待办和房间消息，对外改名后仍保留旧的 `lolPing` 数据目录及内部标识。

| 平台 | 设置目录 |
| --- | --- |
| Windows | `%APPDATA%\lolPing` |
| macOS | `~/Library/Application Support/lolPing` |
| Linux | `$XDG_CONFIG_HOME/lolPing`，通常是 `~/.config/lolPing` |

可以通过“设置 → 应用 → 打开设置文件夹”定位。里面可能有 `settings.json`、`deepseek-api-key.enc`、`codex-question-session.json`、待办图片和元数据、自定义表情、缓存以及 Electron 用户数据。设置可能包含房间码和你选用的昵称。

不要把这个目录、加密凭据文件、Codex 登录资料、个人截图、日志和本机配置放进源码压缩包或 Git 提交。全新源码不包含已配置的 Key、个人待办或房间资料，使用者在自己的设置里填入凭据。不要把已配置好的个人用户数据目录当成软件发行包分享。

## 常见问题与限制

| 问题 | 排查方式 |
| --- | --- |
| 没有触发 AI | 检查模式和服务。单次普通信号只显示标记，房间信号和设置预览也不会触发 AI。 |
| 提示缺少 Key 或 Codex 未就绪 | 保存自己的 Key，或打开、登录 Codex 并确认命令行工具可用。 |
| 回答慢或失败 | 检查网络、账户权限和服务额度。“全力进攻”耗时更久，普通动作关闭深度思考；连接测试不保证之后的图片请求一定成功。 |
| 解释错位或内容不完整 | 将原内容置于前台，连打两次框选更完整或更精确的范围。固定范围可能遗漏上下文，小字也可能无法识别。 |
| Mac 截图失败 | 检查屏幕录制和辅助功能权限，未签名或更新后的程序可能需要重新授权。 |
| 编辑内容时 Ctrl + 拖动打开表情 | 在“设置 → 表情”中修改或关闭表情触发键。 |
| 在游戏或管理员窗口上打不开轮盘 | 可能受“全屏程序中暂停”、独占全屏或 Windows 权限隔离影响。先在普通窗口检查触发设置。 |
| Linux 快捷键冲突 | 更换触发键，或修改桌面的 Alt + 拖动绑定。不支持 Wayland。 |

共享整个屏幕可包含普通信号层，只共享单个应用窗口可能不包含。框选限于打信号的那块屏幕，过小的选框会被拒绝。AI 可能误读或误解图片，来源链接也不是自动事实核查。

## 开发与构建

```sh
npm run typecheck
npm run test:helper
npm test
npm run build
```

Windows 重建原生输入助手前请退出正在运行的软件，避免其可执行文件被占用。

| 命令 | 输出／用途 |
| --- | --- |
| `npm run dev` | 以开发界面运行 Electron |
| `npm run build` | 构建主进程、预加载和界面到 `out/` |
| `npm start` | 运行构建后的软件 |
| `npm run dist` | 生成 Windows 安装包 `release/lolPingMind-ai-Setup-<version>.exe` |
| `npm run dist:mac` | 在 Mac 上生成 `release/lolPingMind-ai-<version>-arm64.dmg` |
| `npm run dist:linux` | 在 Linux 上生成 AppImage 和 Debian 包到 `release/` |
| `npm run dev:site` | 运行继承的浏览器轮盘演示，不包含桌面 AI 流程 |

有打包目标不代表已经存在公开发行版。继承的原版发布工作流需要单独审查并配置为本分支后才能发布。`out/`、`release/`、原生构建和本机用户数据不应进入 Git。

主要代码：[主进程](src/main)、[共享设置／协议／翻译](src/shared)、[问答界面](src/renderer/question)、[框选界面](src/renderer/capture)、[原生输入助手](native/hook-helper)。修改前请阅读 [AGENTS.md](AGENTS.md)。[设计说明](docs/design.md)、[macOS 说明](docs/design-macos.md) 和 [Linux 说明](docs/linux.md) 记录了继承的架构与本分支新增功能。新逻辑需要行为测试，输入和窗口变更需要在对应系统实机运行。
